# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

MoMetadata processes all user files locally in the client browser using Web APIs without transmitting any file data or telemetry to remote servers.

If you discover a security vulnerability or privacy concern within MoMetadata:
1. Please do **NOT** open a public issue.
2. Email the developer directly at `dimasmong.dev@gmail.com` with a description of the vulnerability and steps to reproduce.
3. You will receive an acknowledgment within 48 hours and updates regarding mitigation.
